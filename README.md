## ⚡ البنية التقنية والمحركات الثلاثة (Architecture)

### 1. مودم الموجات الصوتية (Acoustic Wave Modem)
نظام نقل بيانات فيزيائي يعتمد على الموجات الصوتية لنقل الحزم عبر مكبر الصوت والاستماع إليها عبر الميكروفون:
* **التعديل الترددي (Modulation):** يستخدم تقنية **Continuous-Phase Frequency Shift Keying (CPFSK)** لمنع التكتكات الصوتية وضمان استمرارية الطور ومقاومة التشويه الصوتي في البيئة المحيطة.
* **نطاقات التردد المدعومة:**
  * **النطاق المسموع التكتيكي (Audible Cyber):**
    - نغمة المزامنة (Sync Chirp): `2600 Hz`
    - نغمة الواحد المنطقي (Mark 1): `2200 Hz`
    - نغمة الصفر المنطقي (Space 0): `1800 Hz`
    - معدل الباود: ~35-40 باود بموثوقية فائقة حتى مع الضوضاء المحيطة.
  * **النطاق فوق الصوتي الصامت (Stealth Near-Ultrasound):**
    - نغمة المزامنة: `19500 Hz`
    - نغمة الواحد: `18500 Hz`
    - نغمة الصفر: `17500 Hz`
    - بث ونقل صامت تماماً غير مسموع للأذن البشرية.
* **الاستقبال والتحليل الحي:**
  - تسجيل أحادي 16-بت بتردد عينات 44.1 kHz عبر `AudioRecord`.
  - معالجة الإشارة الترددية اللحظية عبر خوارزمية **Goertzel** لحساب طاقة الترددات بدقة متناهية.
  - مرسمة ذبذبات حية (**Live Oscilloscope Canvas**) ومؤشرات طاقة رقمية بالديسيبل.
  - تأطير الحزم وفحص التحقق الدوري من الأخطاء (**CRC16**).

### 2. الناقل الضوئي بالباركود المتدفق (Optical Stream Matrix)
نظام لنقل الملفات الضخمة والصور والوثائق عبر شاشة الهاتف وكاميرا الجهاز الآخر كشلال ضوئي:
* **تجزئة الحزم المتدفقة:**
  تقسيم الملف إلى حزم صلبة ذاتية التوثيق بالصيغة:
  ```text
  W6G|<fileId>|<chunkIndex>|<totalChunks>|<fileName>|<crc32>|<Base64Payload>
  ```
* **محرك التوليد الضوئي:**
  - توليد مصفوفات QR Code قياسية عبر خوارزمية **ZXing** بدقة عالية وتصحيح أخطاء المستوى المتوسط (Error Correction Level M).
  - سرعة تدفق قابلة للتعديل من إطارين إلى 12 إطاراً في الثانية (2–12 FPS).
* **المستقبل والماسح بالكاميرا (`CameraX`):**
  - تحليل إطارات الكاميرا في الوقت الحقيقي بدون تأخير عبر `QrCameraAnalyzer`.
  - مصفوفة رسومية تفاعلية (**Chunk Grid Matrix**) تضيء بالأخضر للحزم المكتملة وبالأصفر للحزمة الجارية وبالرمادي للحزم المفقودة.
* **البروتوكول العكسي للحزم المفقودة (NACK Reverse QR):**
  - في حال سقطت أي حزمة أثناء المسح، يولد التطبيق كود QR عكسي يحتوي قائمة الحزم المفقودة فقط (`W6G_NACK|<fileId>|<missing_list>`) ليقوم الهاتف المرسل بإعادة بثها دون الحاجة لإعادة إرسال الملف من البداية.
  - إعادة تجميع الملف فورياً في ذاكرة التخزين مع خيارات الفتح والنسخ والمشاركة.

### 3. شبكة الجيل السادس المباشرة (Nexus-6G Direct Mesh Protocol)
بديل كامل للبلوتوث وشبكات الإنترنت، مصمم للربط المباشر بين جهازين فقط عبر نفق مقبس عالي السرعة (High-Throughput P2P Socket):
* **طريقة العمل بدون إنترنت أو راوتر:**
  1. يقوم الجهاز الأول (Gateway Host) بتشغيل نقطة اتصال (Wi-Fi Hotspot) أو الربط اللاسلكي المحلي، ويشغّل خادم البوابة على المنفذ `8888`.
  2. يعرض الجهاز الأول كود QR سريع يحتوي عنوان الـ IP المحلي: `N6G://192.168.43.1:8888`.
  3. يقوم الجهاز الثاني (Peer Client) بمسح الكود أو كتابة الـ IP والضغط على "اتصال".
* **التأطير الثنائي لبروتوكول Nexus-6G (Binary Framing):**
  ```text
  +----------------+---------+--------+------------------+---------------+--------+
  | Magic (2B)     | Ver(1B) | Op(1B) | Length (4B BigE) | Payload (...) | CRC(2B)|
  | 0x4E, 0x58 (NX)|  0x01   |  0x..  |     0x00000000   |   Raw Bytes   |  CRC16 |
  +----------------+---------+--------+------------------+---------------+--------+
  ```
  - `0x01` HANDSHAKE: مصافحة تأسيس الرابط.
  - `0x02` HEARTBEAT / PING: نبضات قياس زمن الاستجابة والـ Jitter بالملي ثانية.
  - `0x10` DIRECT_MESSAGE: محادثة فورية مشفرة بين الجهازين.
  - `0x20` FILE_MANIFEST: إعلان الملف (الاسم، الحجم، نوع المحتوى).
  - `0x21` FILE_CHUNK: حزم الملفات المنقولة بحجم 64 كيلوبايت لكل حزمة لأقصى استغلال لنطاق الـ Wi-Fi.
  - `0x23` FILE_COMPLETE: إشعار اكتمال النقل والتحقق من سلامة البيانات.
* **لوحة القياس الحية (Telemetry HUD):**
  - قياس سرعة النقل الحقيقية بالميغابايت في الثانية (MB/s).
  - قياس زمن الاستجابة (Ping Latency ms).
  - عدادات الحزم الصادرة والواردة.

---

### 4. فاحص الحزم وخزينة الملفات (Packet Inspector & File Vault)
- **محلل الحزم (Packet Sniffer):** تسجيل كل بايت يمر عبر الصوت أو الباركود أو شبكة 6G، مع استعراض الهيدر والترميز السداسي عشري (Hex Viewer) والتأكد من فحص الـ CRC.
- **خزينة الملفات (Vault):** حفظ كل الملفات والنصوص المستلمة مع إمكانية الفتح والتصدير المباشر عبر نظام أندرويد.
